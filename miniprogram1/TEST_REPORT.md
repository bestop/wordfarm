## 六-B、游戏开始按钮错误修复记录

> 修复日期：2026-08-02
> 触发条件：用户在首页点击"开始游戏"按钮时发生错误，无法进入游戏界面。

### 根因分析

| 编号 | 错误 | 触发条件 | 影响范围 |
|---|---|---|---|
| BUG-01 | `ctx.roundRect is not a function` | 基础库 < 2.31.0 或部分安卓机型 Canvas 2D 不支持 roundRect | 渲染器离屏缓存构建即崩溃 |
| BUG-02 | Canvas 节点获取失败 | onReady 后 WXML 首帧未完成渲染，`query.select('#gameCanvas')` 返回空 | 游戏画面无法初始化 |
| BUG-03 | 异步回调错误逃逸 | `exec` 回调内异常未被捕获，导致初始化流程静默失败 | 无错误提示，玩家卡死 |
| BUG-04 | 渲染错误导致主循环崩溃 | 单帧渲染异常未处理，requestAnimationFrame 链断裂 | 游戏卡死无恢复 |

### 修复措施

| 编号 | 文件 | 修复内容 |
|---|---|---|
| FIX-01 | `utils/renderer.js` | 新增 `roundRectPolyfill`（贝塞尔曲线模拟圆角）+ `safeRoundRect`（优先原生，降级 polyfill）；替换全部 `ctx.roundRect` 调用 |
| FIX-02 | `utils/renderer.js` | `attach()` 内 `_buildOffscreenCache` 加 try-catch，失败降级为实时渲染；`render()` 加整帧 try-catch，连续 5 次失败触发 `onRenderFatal` |
| FIX-03 | `pages/game/game.js` | 新增 `_tryInitCanvasNode` 重试机制（最多 5 次，间隔 100ms）；`exec` 回调内独立 try-catch；新增 `_showInitError` 模态框引导返回首页 |
| FIX-04 | `utils/gameManager.js` | `start()` 加 try-catch 并绑定 `renderer.onRenderFatal`；`_loop()` 加 try-catch，连续 3 次异常终止游戏并回调 `onGameOver` |
| FIX-05 | `components/quiz-panel/quiz-panel.wxml` | 选项区增加 `wx:if="{{question && question.options}}"` 空值保护，防止题目未就绪时渲染异常 |

### 验证结果

| 验证项 | 方法 | 结果 |
|---|---|---|
| 语法检查 | `node --check` 全部 13 个 JS 文件 | ✅ 全部通过 |
| 错误处理链路 | 代码审查：init → retry → render → loop 四层防护 | ✅ 完整覆盖 |
